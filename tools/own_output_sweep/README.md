# Reproduce the own-output audit

These scripts audit existing updated-producer jobs. They do not launch a design run, call an LLM provider, resume the paid queue, generate drawings or load a physical supplement. Native re-export uses the job's own configuration and saved calculation records with analysis disabled.

The original verification workspace is required: `outputs/workflow_fresh_61/plan.json`, its original architectural handoffs, `outputs/workflow_six/workflow_report.json`, the corresponding local HR/CFS job folders, native repository checkouts under `work/repos`, and the two native virtual environments under `work/envs`. Missing jobs are reported as unavailable, never replaced by the old gold models. The inventory has 61 primary identities and six separately labelled earlier controls.

Set `STELTIC_SWEEP_WORKSPACE` to that workspace. Copy these Python files into its `work/stage15` directory and copy `geometry_checks.py` into `work/stage13` (or retain the identical original helper). Keep an earlier audit directory if preserving a previous run; the default output is `outputs/own_outputs_61`.

1. Use the HR environment to run `audit_sources.py` without arguments to create the inventory, then `audit_sources.py HR`. Use the CFS environment for `audit_sources.py CFS`. These steps evaluate native completion, current package validity and recorded-source freshness without modifying the jobs.
2. Run `replay_outputs.py` with the HR environment. It dispatches each native model-only replay through the appropriate environment into a separate output directory, verifies analysis is disabled and checks original file hashes. No producer source or design record is rewritten.
3. Run `run_exchanges.py` with the HR environment. It uses two bounded pipelines. The actual openBIM router snapshots and exports each current own package, imports/builds the IFC, returns it, imports/builds again and compares every original STEP entity and every product's complete geometry/data. Stale/invalid packages must reject a new snapshot; missing ones stay unavailable. `OPENBIM_AUDIT_CODE` optionally selects an isolated openBIM `src` directory for a fix retest.
4. Run `run_checks.py`. It binds an original architectural handoff by source SHA solely for comparison; it never injects its geometry into the returned model. It checks source completeness, datums, grids, opening boundaries/clearances, floor/roof planes and voids, panel classification, orientations, selected records and connection occurrences. Unknown placement remains unknown. A missing matching input is explicitly unverifiable.
5. Run `verify_import_findings.py <openBIM-src-directory>`, `verify_integrity.py`, `report_outputs.py` and `write_fix_list.py`. Final evidence must account for every identity and every variant; passing IFC transport is separate from source completeness and original native completion.

The fixed processing scope remains all objects, original IFC units, 100 MB / 100,000 products / six million triangles, with no silent exclusions or simplification to obtain a pass. Fully voided panels are labelled original-boundary references and counted separately from surfaces. The suite is a data/geometry exchange audit; it does not establish structural capacity, fabrication fit or native Revit acceptance.
