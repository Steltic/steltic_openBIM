# CFS10 and CFS18 roof bearing seats

Main-roof heel details now extract the actual finite header cap and paired
header, or a real welded HSS closure plate when the heel falls over a frame
column. They no longer draw a generic stud and track as the roof support.

The source truss reaction and supplier requirements remain attached. Closure
plates, local column end cuts, solid bearing shims and two retention bolts per
heel are explicit accepted fictional fit inputs (A). Their capacity is not
verified by the saved gold design. Source inputs and calculations are unchanged.

Six roof-seat tests cover every heel in both buildings, actual bolt contact in
each connected solid, full heel support and closure-to-HSS elevation. Together
with eight header tests, 14 tests pass. Development receiver-fit audits have no
remaining failures for the new roof-seat or column-cap families.

Nine selected preview sheets per building were visually inspected: C001-C004,
C007-C008, C045-C046 and C051. These show both header directions, centered and
offset column heels, bearing shims and the real HSS closure weld. This is preview
validation; full building acceptance remains pending the other connection work.
